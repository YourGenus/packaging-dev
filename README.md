# Genus Packaging Development

Genus is the next‑generation consumer brand.  
We are currently prototyping sustainable‑by‑design packaging systems, exploring modular forms using **Aluminum** and **PCR** as core materials, and building a modern platform for rapid iteration.  
We are engineering the identity‑driven future.

---

## Purpose

This repository contains early explorations, prototypes, and schema foundations for the Genus packaging system, including:

- Modular packaging architecture  
- Aluminum + PCR hybrid components  
- Parametric and code‑driven design  
- Genre‑based identity systems  
- Rapid iteration workflows using modern tools and AI  

---

## Core Schema

The Genus Core Schema defines the building blocks of the system:

- **Genres** — identity frameworks (Citizen, Athlete, Dreamer, Metropolitan, Traveler)  
- **Product Categories** — cleanser, mist, serum  
- **Types** — standard, extended, compact, insert‑only  
- **Parts** — shell, insert, cap  

These components form the foundation for future automation, 3D generation, and product configuration.

---

## Materials

Genus focuses on circular, sustainable materials:

- **Aluminum** — durable, infinitely recyclable  
- **PCR (Post‑Consumer Recycled plastics)** — lightweight, responsible, refill‑friendly
